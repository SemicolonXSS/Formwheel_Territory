# Formwheel Territory ⚔️

전략 영토 점령 게임. [Formwheel HUB](https://semicolonxss.github.io/Formwheel/)로 돌아가기.

## 현재 구현
- 솔로 AI (쉬움 / 보통 / 어려움)
- 한 기기에서 플레이하는 2인 및 4인 모드 (핫시트)
- 7×7 보드, 10/15/20턴, 클래식/장애물/특별 지역 맵
- 동시 명령: 확장/공격/방어, 같은 칸을 두 명 이상 차지하려면 충돌하여 실패
- 핵심 지역 3점 / 일반 칸 1점, 최고 점수 승리
- 모바일 반응형 UI

## 플레이
GitHub Pages가 이 저장소의 **main / root**로 활성화되어 있으면 https://semicolonxss.github.io/Formwheel_Territory/ 에서 실행할 수 있습니다.

## 앞으로 필요한 작업
- Firebase 방 코드 기반 **서로 다른 기기** 실시간 배틀 (현재 제공되지 않음)
- 안전한 서버 측 턴 처리 / 인증 및 DB 규칙
- Formwheel ID 연동, 업적, 기록, 리더보드
- 자동화된 테스트 및 여러 기기 실제 검증

온라인 기능이 준비되기 전까지 HUB 카드의 연결 종류는 오프라인으로 표기합니다.
